# Good Practices for Software Development

## Question 1: Which point(s) were new to you?

- **Gathering requirements** was new to me. As a fresher, I did not know much about how to properly gather the requirements. Now I understand the importance of taking notes, asking questions during discussions, and confirming clarity before starting implementation.

- **Always over-communicate** was another important learning for me. I used to stay silent most of the time, but now I realize how important communication is in building a project and completing it within the deadline.

---

## Question 2: Which area do you think you need to improve on? What are your ideas to make progress in that area?

### Improving Communication

As a developer, I sometimes try to fix issues for too long before asking for help. I need to improve on:

- Asking earlier when stuck  
- Structuring my questions properly  

If I’m stuck for more than 30–45 minutes, I will prepare a structured message that includes:

- What I am building  
- Expected behavior  
- Actual behavior  
- Error message  
- What I tried  

This approach will help others understand my problem clearly and respond faster.
